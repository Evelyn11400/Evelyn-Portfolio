# Evelyn Li — Product Designer

An English-language product design portfolio with a Tempo case study. The site is a static Next.js export with responsive layouts and motion that respects reduced-motion preferences.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repository in Vercel. Use the Next.js framework preset and the default build command. No environment variables are required. The production domain can be set to `evelynli.work` after deployment.

## Content

- `app/page.tsx` — homepage, work, about, contact
- `app/work/tempo/page.tsx` — Tempo case study
- `app/globals.css` — visual styles and animation

The contact link currently points to `hello@evelynli.work`; update it if a different address should receive messages.
